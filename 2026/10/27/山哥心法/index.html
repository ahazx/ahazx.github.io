    02 信心问题（日期未记）

    下半年创业板跌了43%，有时候不要怨自己，有没有可能是大环境太差了。

    没法稳定盈利那就拿10w以下的资金，经历的太少了才几个月就扛不住了。建议翻一番15年到18年11月几个指数的k线图，这里3500跌到1500创业板。你们没自信正常的，因为你们经历的太少了。像我那个朋友，今年还是亏钱的，但是不缺自信，因为都是自己赚出来的，有自己的模式。

    这种行情比如上周末我复盘，就是找到自己交易的问题，找到了改正就行，行情差才能进步，行情好很难进步的。行情好你赚的不是你的能力大多数是运气，但是行情差你亏钱亏的是自己的能力，再这里面去找原因，打磨交易系统。为啥18年是我的跃迁之年，因为18年是大熊市，最差的一年。扛过去完善自己的系统，行情好了才能赚钱。

    不要怕亏，但是怕亏的不明不白。

    为啥我可以跑得果断一些，你们做不到那种执行力，因为你们没有肌肉记忆，或者说总结的不够多。

    04 抄底指数的判定：银行杀跌 + 指数与个股情绪背离（2026-11-03）

    银行砸了两根阴线，早上指数跌那么狠，但是跌停都没几个，所以抄底了指数。

    两件事叠在一起看：

    1. 银行杀跌——砸盘的动力来自权重（银行这类大块头），不是全市场在跑。
    2. 指数和个股情绪背离——指数跌得很凶，但个股情绪没跟着崩（跌停没几个）。指数是被权重拖下去的，不是市场真的慌了。

    这个背离就是买点：指数难看，个股没坏。
    反过来就完全不是一回事：

    盘面 含义 动作
    银行杀跌 + 指数跌得凶 + 跌停没几个 指数与个股情绪背离，跌的是权重 可以抄指数
    指数跌得凶 + 跌停一片 指数和个股一起崩，没有背离，是真恐慌 别抄，后面还有跌

    核心：看的是指数和个股情绪有没有背离。跌的是权重、个股情绪没坏，这才是指数的买点；
    指数和个股一起杀，那就不是买点，是下跌中继。    （2026.11.3 自己的观察，当天 1.245 抄中证南方ETF 的依据）

    05 高位与低位：为什么只做低位低吸（2026-11-07）

    5.1 立场

    **我不喜欢高位票。**高位放量和低位放量，意义不一样。这是「做低吸」和「做趋势」的区别——两套打法，不能混着做。看位置、确定趋势，那肯定不会亏。

    5.2 先定义清楚：低吸 ≠ 接刀

    低吸不是”跌了很多就买”，低吸是”低位启动”。低吸和下降趋势是两回事。判断看当天的盘面，不是看它跌了多少。

    5.3 最重要的一句：低位放量上涨，不是买点

    **低位放量只说明资金进来了，不说明为什么进来。**买点 = 找到催化 + 找到预期空间。低位上涨一天能涨很多，这时候要去找它的逻辑，不是追它的涨幅。找到催化、算出空间，才是买点。

    5.4 空间怎么算：逻辑决定空间

    有没有逻辑 空间
    没有逻辑 约 20 个点
    有逻辑 30～50 个点
    低位极品 可能到 50～70 个点

    大涨的时候，3 天就 20 个点。所以 20 个点也是买点，自己算。

    5.5 为什么低位有价值：预期没被定价 vs 预期已经含在估值里

    高位的票，它的估值里面已经含了预期。 故事讲完了、预期打满了，价格里装的就是”未来会很好”这件事本身——你买入的是别人的预期，不是预期差。

    低位的票，有很多预期还没有被包含进去。 市场还没给它定价，所以才有预期差，才有价值。

    价格里装了什么 你买入的是什么
    高位 预期已含进估值，打满了 别人的预期（没有差值）
    低位 预期还没被包含进去 预期差（还没被发现的那一段）

    这就是低吸能赚大钱的根本原因：赚的是”预期还没被定价”到”预期被定价”的那一段。

    一句话：高位买的是已经写进价格的预期，低位买的是还没写进价格的预期。

    5.6 操作节奏

    先看到异动，再去找原因。（”昨天盘中我就看到了，只是没找到原因”）

    只要做好大涨，就不会错过。

    我的补注（2026.11.7 自己的理解，非山哥原话）

    异动之后要确认的是板块和资金：板块有没有跟、资金有没有接。
    只有个股自己动、板块不动、资金不接，那叫异动，不叫行情——涨一天就完了。
    板块是方向，资金是力度。两个都有，才做得出来幅度。

    这段话正好解释了 11-06 清仓特一药业

    特一药业 11-05 买入时的样子，就是标准的”低位放量上涨“：连涨两天、同类在涨。

    但按山哥这套标准过一遍：

    • 找到催化了吗？ 没有——只有”流感咳嗽预期”这种泛泛的季节性说法，没有具体事件
    • 有预期空间吗？ 算不出来——三季报 -24.18%，业绩在往下走
    • 是低位启动吗？ 不是——已经连涨两天，进的是第二段

    三条全不满足，所以它根本不是买点。 11-06 清仓，从”没有持股理由”这个角度是对的，但从”一开始就不该买”这个角度，买的那天就错了。

    以后判断买点：先问催化，再问空间，最后才看涨幅。顺序反了，就是追涨。

    06 情绪与轮动：从个股升到概念维度（2026-11-09）

    以前做得多的是单票埋伏、独立市场那种——看一只票自己的位置、催化、空间。
    今天讲的是情绪：跳出个股，先看板块在哪个阶段、资金在第几轮、我是第几手。
    个股是一维，板块情绪是二维。这是一次维度升级。

    6.1 先手决定这笔钱从哪来

    今天又是全部拉高轮一遍，直接把板块拉高潮——航天、机器人、短剧都是这样。

    但凡你不是上周五买的，今天盘中买入，很难赚钱。

    全文最狠的一句

    今天赚的是明天的买盘。

    追高买进去的人，盈利来源不是公司、不是逻辑、不是业绩——是”明天还有人肯用更高的价接”。
    这本质是击鼓传花。鼓什么时候停，不归你定。

    所以买之前第一句该问的不是”它还能涨吗”，是——“我是第几手？”

    6.2 题材要分层：都是概念，靠谱度差很远

    题材 靠谱度 依据
    机器人 较高 大概率这两年落地，有产业进度可跟踪
    太空光伏 比机器人还不靠谱 很难，短期看不到落地路径

    判断标准不是”听起来大不大”，是”有没有可验证的落地进度”。
    同样是”概念”，有的在兑现路上，有的只是故事。给同样的仓位，是在赌两件不同概率的事。

    6.3 没有先手就休息；有消息也得看买点

    没有自己提前预判的先手板块，就休息。

    有消息刺激的也不是不能做，前提是你得有个好买点。 而消息本身要辩证看，过三关：

    关卡 问法 判错会怎样
    炒过没有 第一次出来，还是第 N 次翻新？ 炒过的题材，利好就是出货
    级别多大 部委级 / 行业级 / 公司级？ 级别决定空间，公司级只有几个点
    买点在哪 消息出来是启动点，还是已经高开？ 高开就是别人先手，你是接盘

    案例：tk 出海（2026.11.9）

    上周五看好 tk 出海，周末吹得很厉害，结果全部高开低走，一个都没走出来。
    被吹得最响的时候，往往就是先手兑现的时候。
    结论不是”以后不看消息”，是——该止损还得止损。 消息再对，买点错了照样亏。

    6.4 情绪要感受，但要承认它会让你的手变形

    • 计划是你自己的计划，市场怎么走，得去知道。 两件都要，缺一个都不行。
    • 今天明显是轮动的情绪高点——涨的是”轮到谁”，不是”谁更好”。
    • 更要承认一件事：有时候即使看到了，盘中也会被情绪左右。盯着分时K线、盯着自己的持仓，明明知道该怎么做，就是做不出理智正确的操作。

    这条不是让你”努力克服”，是让你”提前绕开”

    盘中你的判断力会打折，这是生理事实，不是意志力问题。
    所以止损止盈必须在开盘前就定成数字，盘中只负责执行，不负责判断。
    靠盘中自律 = 靠不住。靠开盘前写死的数字 = 靠得住。（对应交易系统第 8 条）

    6.5 资金先动，属性后补

    很多时候是它先板了，资金才去找它的属性。

    顺序是：涨停 → 资金挖掘概念 → 概念被讲出来 → 更多资金进来。

    这解释了为什么”逻辑”常常是涨出来之后才有的。

    所以两头都不能做错：

    • ❌ 等逻辑讲清楚再买 → 那时已经涨完了
    • ❌ 买了之后才去编逻辑 → 那是给自己找安慰

    ✅ 异动出现时去找逻辑，找得到就做，找不到就不做。（呼应【高位与低位】第三节）

    6.6 盘感可以统计，不是玄学

    判断一个板块的温度，每天问这六句：

    1. 涨了多少天了？ 第 1~3 天是启动，第 5 天以上是接力。
    2. 龙头是谁？ 有没有明确的领涨，还是群龙无首。
    3. 后排是谁？ 有没有第二梯队跟风。
    4. 有没有高位滞涨？ 龙头涨不动了，就是退潮前兆。
    5. 有没有开始杀跌？ 第一个跌停出现，退潮确认。
    6. 前排带不动后排，还是后排推不动前排？
      • 前排带不动后排 = 只有龙头硬撑，板块没承接 → 弱
      • 后排推不动前排 = 跟风的都涨了、龙头反而滞涨 → 更危险，是最后的普涨

    盘感 = 这六个问题的历史答案。
    你不是”感觉”它到顶了，是你记得上一次涨到第五天、龙头开始滞涨之后发生了什么。
    所以盘感要记，要统计——不统计的感觉只是情绪。

    6.7 这一节真正的落点

    维度 看什么 能赚到什么钱
    一维：个股 位置、催化、空间、买点 个股的钱
    二维：板块情绪 涨几天了、第几轮、前排后排、我是第几手 判断”这波该不该参与”

    二维能力最大的价值，不是让你多做，是让你知道什么时候不做。

    不参与也是一种操作，而且往往是最赚钱的那种。（2026.11.9 空仓开局，本身就是这个判断）

    07 情绪见底：弹簧两端修复（2026-11-20）

    情绪今天见底了 抗跌的指数在补跌，前面背离了3天，今天背离解除的话就是短期底部了。强势的全部补跌了，弱势的反而今天杀得没那么凶了，看下跌幅榜微盘指数也是，跟上证和科创背离和解了，科创上证向下。情绪见底了，情绪一般先指数见底，从前往后，一个一个杀跌，最先杀的开始企稳了，最抗跌的补跌，也就是弹簧两端修复了，常规情况是这样的。强势股补跌，全部杀一遍，如果情绪继续触底 银行也要杀。你不要看指数，要看情绪。看下跌幅榜跌停都要没了，跌停最少的一天。这种跌了好久的，反弹是要持续几天，还是弹一下给逃命机会，情绪上看呢，要要配合数据
