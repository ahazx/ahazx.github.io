## 🛠️ 技术栈

- **静态站点生成器**：[Hexo 8](https://hexo.io/)
- **主题**：自改版 `bear` 主题（[Pug](https://pugjs.org/) 模板 + [Stylus](https://stylus-lang.com/) 样式）
- **部署**：GitHub Pages（`main` 分支）
- **内容格式**：Markdown

## ✨ 站点特性

- 🗂️ **可收起的目录**：左侧目录按「年 → 月 → 文章」三级归档，随时展开/收起，快速定位。
- 🔍 **站内搜索**：支持全文关键词检索。
- 🧩 **卡片式首页**：按年份分组、双列卡片布局，一眼纵览全部文章。
- 🏷️ **按分类浏览**：支持 `life` / `work` / `运营·方法论` 等分类聚合浏览。
